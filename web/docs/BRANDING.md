# 平台名称与图标

管理员可在“系统设置 → 平台品牌”修改显示名称、副标题及图标。保存后的设置用于登录页、侧栏、浏览器标题和网站图标；配置通过所选数据库持久化。

项目的默认显示名称为 **MindIE-Motor Console**。自定义名称、副标题和图标由数据库保存；需要默认品牌时，在该设置中恢复默认并保存，不修改数据库文件或删除品牌记录。

## 修改步骤

1. 以系统管理员登录控制面，打开平台品牌设置。
2. 填写名称与副标题，可选择静态图片并检查预览。
3. 保存后查看侧栏和浏览器标题，并在未登录页面核对品牌显示。
4. 不需要自定义品牌时使用界面中的恢复默认选项，再明确保存。

名称为1..40字符，副标题不超过80字符，不接受控制字符或不可见格式字符。客户端接受不超过2 MiB、尺寸不超过4096×4096的静态 PNG、JPEG 或 WebP，规范化为 PNG；服务端最终校验非交错8位 RGB/RGBA PNG、单边不超过512像素及文件不超过256 KiB。动画和 SVG 不作为品牌图标导入。

配置按修订号保存。409表示配置已被其他操作修改，保留当前输入，读取最新设置并对比后再提交；不要反复覆盖。普通运维和只读角色没有修改权限。

## 显示品牌与技术身份

显示设置不改变 `motor-console` 产品身份、数据库身份、Cookie、协议、容器名、部署目录或原生 Motor。平台采用客户端系统字体，不随源码打包专有品牌图片或自定义字体二进制。

Compose 项目名、监控看板 UID、指标序列名及插件包格式是部署或接口标识，和页面名称分别维护。修改品牌时沿用这些标识，避免另起容器、创建新数据目录或断开历史监控。需要迁移这些标识时，应单独核对数据、归属、查询及回退方案。

登录页需要在登录前读取品牌，因此显示名称、副标题与已保存图标属于公开展示信息，不能放入密钥、内部地址或个人敏感资料。上传的图标及品牌配置是部署数据，不属于公共源码仓库的静态资源。

部署配置停用内置品牌模块后，宿主展示默认品牌；既有数据库记录不会因此删除。数据库恢复会恢复相应的品牌配置，见[备份与恢复](../BACKUP_RECOVERY.md)。
